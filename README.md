# Restaurant Billing System (Java)

## Project Description
This is a console-based Restaurant Billing System developed using Core Java.
It allows users to add menu items, remove items, calculate total bill,
apply GST, and generate an itemized receipt.

## Features
- Add menu items dynamically
- Remove items from order
- Automatic bill calculation
- GST calculation (5%)
- Console-based interface

## Technologies Used
- Java
- OOP Concepts
- ArrayList

## How to Run
1. Compile the program:
   javac RestaurantBillingSystem.java
2. Run the program:
   java RestaurantBillingSystem
